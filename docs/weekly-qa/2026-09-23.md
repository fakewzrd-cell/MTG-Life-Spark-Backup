## Analyzer/test (short)

`flutter analyze` on stable 3.47.5: 2 infos, no warnings or errors. Both are in `game_overview_view.dart` — deprecated `cacheExtent` (line 181) and `onReorder` (line 376). `flutter test`: 272 passed.

## What works

- The life total is the hero: tabular figures, a color shift at 10 and at 5, 64dp ± edges, and a floating delta.
- Host and Join split the screen into two calm, full-height actions with distinct icons.
- Table keeps End turn pinned, life steppers at 48dp, and seat color on the glance chips.

## Bugs

1. **P1 — Life hold overshoots.** After 500ms, the ± strips add ±5 every 150ms. A one-second hold is about ±20. Onboarding says hold means a single ±5. The table stepper repeats the same way.
2. **P1 — Host skip is invisible.** With phases on, End turn is a 104×52 slice. “Hold to skip {name}” is a second line inside a FittedBox, so it shrinks away. The control looks disabled; long-press is the only skip.
3. **P2 — Forfeit matches End turn.** On Table, Forfeit is another 60dp, 16px bold bar, 8dp under End turn. Only the error tint separates a concede from passing the turn.
4. **P2 — Join permission copy is broken.** `joinCameraDeniedBody` stores a literal `\n`, so the Settings recovery line renders as escaped text on the camera-denied screen.
5. **P2 — Eliminated life is silent.** The eliminated state returns a skull before the Semantics label, so the existing “eliminated at N” string never reaches TalkBack or VoiceOver.

## UI/UX polish

1. **Make End turn the only loud control on your turn.** In phase mode it sits beside Back and Next, while Home, Undo, Timeout, and Table stay equal below. When a timeout is running, Timeout renames itself to End, so two End actions share the thumb zone. Use the full-width accent bar you already have with phases off, and shrink phase steps to text.
2. **Shorten first-run.** Six dense slides, with Skip as a full button on every page. Three slides are enough: life, QR join, turns. “4 to 6 players” is wrong — the lobby allows 1–6. “Scan for a nearby host” sounds like proximity; the action is a QR camera.
3. **Card search should feel like a tool, not a spare icon.** Lookup is a book glyph at 60% opacity, with no label and no focus on open. Errors use the same secondary type as the empty hint, there is no retry, a failed rulings fetch looks like “no rulings,” and results stop at 20 with no cue.
4. **Say “you” the same way everywhere.** The turn banner hardcodes the avatar initial “Y”; the glance strip uses localized “You.” Localize the initial. The strip is one button, so opponent life totals are not announced individually.
5. **Pin Start in the host lobby.** It sits under the QR, seats, match label, and config. Keep the label “Start game” and put “Everyone must be ready” beside it — today the blocker replaces the action name.
